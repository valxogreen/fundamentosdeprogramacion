 Es la capacidad de que una misma entidad, método, objeto o función **responda de diferentes maneras**según el contexto o el tipo de datos con el que se utilice:

- **Polimorfismo en tiempo de ejecución (dinámico):** Permite que un objeto de una clase derivada sea tratado como un objeto de su clase base, ejecutando la versión específica del método que le corresponde a cada subclase (por ejemplo, que clases como _Perro_ y _Gato_, heredadas de _Animal_, respondan de forma distinta al método 

- **Polimorfismo en tiempo de compilación (estático):** Incluye la sobrecarga de funciones o operadores, donde varias funciones comparten el mismo nombre pero reciben distintos parámetros.
